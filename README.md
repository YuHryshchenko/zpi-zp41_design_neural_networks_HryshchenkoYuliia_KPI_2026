## ℹ️ Про проект

Робота присвячена проектуванню та реалізації нейронних мереж для вирішення широкого спектру задач: від базових логічних функцій до обробки та аналізу тексту, зображень та голосу. Проєкт охоплює використання сучасних архітектур, таких як CNN, RNN, LSTM, а також використання передтренованих моделей (AlexNet, InceptionV3, Xception). У межах курсу розглядаються методи комп'ютерного зору, аналізу настроїв (Sentiment Analysis) та перетворення мови в текст (Speech-to-Text).

### 🎯 Мета роботи
Опанувати теоретичні основи та практичні навички проектування, навчання та розгортання інтелектуальних систем на основі нейронних мереж для автоматизації аналізу складних даних.

## 🔬 Опис лабораторних робіт

### 1️⃣ Лабораторна робота №1: Реалізація та дослідження нейронної мережі Перцептрон для логічних функцій
Написати програму, що реалізує класичну нейронну мережу Перцептрон та навчити її виконувати логічні функції для 4-х змінних.

#### 🎯 Мета
Ознайомитись з архітектурою найпростішої нейронної мережі — перцептрона Розенблатта, вивчити алгоритм його навчання (правило Хебба або дельта-правило) та реалізувати механізм класифікації лінійно роздільних даних.

#### 🧩 Технічні деталі та компоненти
*   **Вхідні дані**: 4-вимірні вектори, що представляють комбінації значень логічних змінних ($2^4 = 16$ станів).
*   **Архітектура**: Одношаровий перцептрон з адаптивними вагами та зміщенням (bias).
*   **Функція активації**: Порогова функція (Step function) для прийняття рішення про клас.
*   **Навчання**: Процес ітеративного оновлення ваг на основі помилки прогнозування для досягнення нульової помилки на тренувальному наборі.
*   **Логічні оператори**: Моделювання функцій AND, OR, NOT та аналіз обмежень перцептрона (на прикладі XOR).
*   **Інструменти**: Python, бібліотека `NumPy` для матричних обчислень та `Matplotlib` для побудови графіків навчання.

### 2️⃣ Лабораторна робота №2: Реалізація та дослідження базових архітектур нейронних мереж для моделювання функцій двох змінних
Написати програму, що використовує різні типи нейронних мереж для апроксимації математичної функції $f(x, y) = x^2 + y^2$.

#### 🎯 Мета
Дослідити здатність різних архітектур нейронних мереж (FeedForward, Cascade, Elman RNN) до регресійного аналізу та моделювання нелінійних залежностей.

#### 🧩 Технічні деталі та компоненти
*   **Математична модель**: Генерація синтетичних даних на відрізку [0, 10] для функції двох змінних.
*   **Досліджувані архітектури**:
    *   **FeedForward**: Класична повнозв'язна мережа з різною кількістю нейронів (10 та 20).
    *   **Cascade Forward**: Модель, де вхідний шар з'єднаний безпосередньо з вихідним (skip-connection), що дозволяє враховувати лінійні компоненти разом із нелінійними.
    *   **Elman RNN**: Рекурентна мережа (`SimpleRNN`), що зазвичай використовується для послідовностей, але в цій роботі адаптована для обробки векторних вхідних даних.
*   **Функції та параметри**: Активація **ReLU**, оптимізатор **Adam**, функція втрат **MSE**.
*   **Метрики оцінки**: Коефіцієнт детермінації ($R^2$), середня відносна помилка та аналіз динаміки навчання через графіки втрат.
*   **Інструменти**: Python, TensorFlow/Keras, NumPy, Scikit-learn (r2_score), Matplotlib.

### 3️⃣ Лабораторна робота №3: Побудова багатошарового перцептрона (MLP) для класифікації візуальних даних
Розробити та натренувати повнозв'язну нейронну мережу (MLP) для розпізнавання рукописних цифр на основі класичного датасету MNIST.

#### 🎯 Мета
Вивчити архітектуру багатошарових нейронних мереж, опанувати принципи роботи алгоритму зворотного поширення помилки (Backpropagation) та навчитися оптимізувати гіперпараметри моделі за допомогою високорівневих API Keras/TensorFlow.

#### 🧩 Технічні деталі та компоненти
*   **Архітектура**: Глибока нейронна мережа (Deep Neural Network), що складається з вхідного шару `Flatten` (для перетворення матриці 28x28 у вектор), декількох прихованих шарів `Dense` та вихідного шару з функцією Softmax.
*   **Функції активації**: Використання **ReLU** (Rectified Linear Unit) для прихованих шарів, що забезпечує швидшу збіжність навчання та запобігає згасанню градієнта.
*   **Навчання та оптимізація**: Використання оптимізатора **Adam** для адаптивного підбору швидкості навчання та функції втрат `sparse_categorical_crossentropy`.
*   **Регуляризація**: Впровадження шарів **Dropout** для запобігання перенавчанню моделі на тренувальних даних.
*   **Аналіз результатів**: 
    *   Візуалізація матриці помилок (**Confusion Matrix**) за допомогою `Seaborn` для виявлення цифр, які мережа плутає найчастіше.
    *   Побудова графіків Accuracy та Loss для моніторингу процесу навчання.
*   **Інструменти**: Python, TensorFlow 2.16+, NumPy, Scikit-learn, Seaborn.
