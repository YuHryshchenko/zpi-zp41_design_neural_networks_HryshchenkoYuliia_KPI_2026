## ℹ️ Про проект

Робота присвячена проектуванню та реалізації нейронних мереж для вирішення широкого спектру задач: від базових логічних функцій до обробки та аналізу тексту, зображень та голосу. Проєкт охоплює використання сучасних архітектур, таких як CNN, RNN, LSTM, а також використання передтренованих моделей (AlexNet, InceptionV3, Xception). У межах курсу розглядаються методи комп'ютерного зору, аналізу настроїв (Sentiment Analysis) та перетворення мови в текст (Speech-to-Text).

### 🎯 Мета роботи
Опанувати теоретичні основи та практичні навички проектування, навчання та розгортання інтелектуальних систем на основі нейронних мереж для автоматизації аналізу складних даних.

## 🔬 Опис лабораторних робіт

### 1️⃣ Лабораторна робота №1: Реалізація та дослідження нейронної мережі Перцептрон для логічних функцій
Написати програму, що реалізує класичну нейронну мережу Перцептрон та навчити її виконувати логічні функції для 4-х змінних.

#### 🎯 Мета
Ознайомитись з архітектурою найпростішої нейронної мережі — перцептрона Розенблатта, вивчити алгоритм його навчання (правило Хебба або дельта-правило) та реалізувати механізм класифікації лінійно роздільних даних.

#### 🧩 Технічні деталі та компоненти
*   **Вхідні дані**: 4-вимірні вектори, що представляють комбінації значень логічних змінних ($2^4 = 16$ станів).
*   **Архітектура**: Одношаровий перцептрон з адаптивними вагами та зміщенням (bias).
*   **Функція активації**: Порогова функція (Step function) для прийняття рішення про клас.
*   **Навчання**: Процес ітеративного оновлення ваг на основі помилки прогнозування для досягнення нульової помилки на тренувальному наборі.
*   **Логічні оператори**: Моделювання функцій AND, OR, NOT та аналіз обмежень перцептрона (на прикладі XOR).
*   **Інструменти**: Python, бібліотека `NumPy` для матричних обчислень та `Matplotlib` для побудови графіків навчання.

## ⚙️ Встановлення та запуск

### 💻 Вимоги
- Python 3.8+

### 🚀 Налаштування середовища

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/YuHryshchenko/zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026.git
   cd zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026
   ```

2. Створіть віртуальне середовище:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/macOS
   # venv\Scripts\activate   # для Windows
   ```

3. Встановіть необхідні бібліотеки:
   ```bash
   pip install numpy tensorflow matplotlib
   ```
   або
   ```bash
   pip install -r requirements.txt
   ```
