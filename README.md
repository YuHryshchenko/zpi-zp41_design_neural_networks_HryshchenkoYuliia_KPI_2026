## 🛠 Стек технологій

### 🤖 TensorFlow & Keras
Основний фреймворк для розробки та навчання моделей глибокого навчання. Keras використовується як високорівневий інтерфейс для швидкого проектування архітектур (Sequential та Functional API).

### 🔢 NumPy
Фундаментальна бібліотека для наукових обчислень, що забезпечує підтримку багатовимірних масивів та високорівневих математичних функцій для роботи з ними.

### 📊 Matplotlib & Seaborn
Інструменти для візуалізації даних. Використовуються для побудови графіків навчання (Loss/Accuracy), візуалізації архітектур та створення теплових карт матриць помилок (Confusion Matrix).

### 🧪 Scikit-learn
Використовується для попередньої обробки даних (масштабування, розділення на вибірки) та оцінки якості моделей за допомогою метрик, таких як $R^2$, Precision, Recall та F1-score.

### 🖼️ Pillow (PIL)
Бібліотека для обробки зображень, необхідна для підготовки вхідних даних (зміна розміру, конвертація форматів) перед подачею у згорткові нейронні мережі.

### 🍎 TensorFlow Metal
Плагін для прискорення навчання нейронних мереж на графічних процесорах (GPU) пристроїв Apple Silicon (M1/M2/M3).

### 📦 Kaggle API
Використовується для програмного доступу до датасетів, що дозволяє автоматизувати процес завантаження та оновлення тренувальних даних безпосередньо в середовище розробки.

### 📁 Pathlib & Shutil
Інструменти для високорівневої роботи з файловою системою, що забезпечують зручну організацію структури каталогів датасету та маніпуляцію файлами зображень.

### 🎥 OpenCV
Бібліотека комп'ютерного зору, що використовується для обробки відеопотоків, зчитування кадрів, зміни їх розміру та підготовки до інференсу нейронною мережею.

### ⏳ Tqdm
Інструмент для візуалізації прогресу виконання тривалих операцій (Progress Bar), що використовується при генерації синтетичного датасету та обробці великих масивів даних.

### 📈 SciPy
Використовується для пост-обробки результатів розпізнавання на відео, зокрема для застосування медіанних фільтрів, що дозволяють усунути короткочасні помилкові спрацьовування.

### 🌐 Urllib & Zipfile
Засоби для автоматизації завантаження ресурсів (логотипів, відео, фонових зображень) з віддалених серверів та роботи з архівами безпосередньо у скриптах.

### 1️⃣ Лабораторна робота №1: Реалізація та дослідження нейронної мережі Перцептрон для логічних функцій
Написати програму, що реалізує класичну нейронну мережу Перцептрон та навчити її виконувати логічні функції для 4-х змінних.

#### 🎯 Мета
Ознайомитись з архітектурою найпростішої нейронної мережі — перцептрона Розенблатта, вивчити алгоритм його навчання (правило Хебба або дельта-правило) та реалізувати механізм класифікації лінійно роздільних даних.

#### 🧩 Технічні деталі та компоненти
*   **Вхідні дані**: 4-вимірні вектори, що представляють комбінації значень логічних змінних ($2^4 = 16$ станів).
*   **Архітектура**: Одношаровий перцептрон з адаптивними вагами та зміщенням (bias).
*   **Функція активації**: Порогова функція (Step function) для прийняття рішення про клас.
*   **Навчання**: Процес ітеративного оновлення ваг на основі помилки прогнозування для досягнення нульової помилки на тренувальному наборі.
*   **Логічні оператори**: Моделювання функцій AND, OR, NOT та аналіз обмежень перцептрона (на прикладі XOR).
*   **Інструменти**: Python, бібліотека `NumPy` для матричних обчислень та `Matplotlib` для побудови графіків навчання.

### 2️⃣ Лабораторна робота №2: Реалізація та дослідження базових архітектур нейронних мереж для моделювання функцій двох змінних
Написати програму, що використовує різні типи нейронних мереж для апроксимації математичної функції $f(x, y) = x^2 + y^2$.

#### 🎯 Мета
Дослідити здатність різних архітектур нейронних мереж (FeedForward, Cascade, Elman RNN) до регресійного аналізу та моделювання нелінійних залежностей.

#### 🧩 Технічні деталі та компоненти
*   **Математична модель**: Генерація синтетичних даних на відрізку [0, 10] для функції двох змінних.
*   **Досліджувані архітектури**:
    *   **FeedForward**: Класична повнозв'язна мережа з різною кількістю нейронів (10 та 20).
    *   **Cascade Forward**: Модель, де вхідний шар з'єднаний безпосередньо з вихідним (skip-connection), що дозволяє враховувати лінійні компоненти разом із нелінійними.
    *   **Elman RNN**: Рекурентна мережа (`SimpleRNN`), що зазвичай використовується для послідовностей, але в цій роботі адаптована для обробки векторних вхідних даних.
*   **Функції та параметри**: Активація **ReLU**, оптимізатор **Adam**, функція втрат **MSE**.
*   **Метрики оцінки**: Коефіцієнт детермінації ($R^2$), середня відносна помилка та аналіз динаміки навчання через графіки втрат.
*   **Інструменти**: Python, TensorFlow/Keras, NumPy, Scikit-learn (r2_score), Matplotlib.

### 3️⃣ Лабораторна робота №3: Побудова багатошарового перцептрона (MLP) для класифікації візуальних даних
Розробити та натренувати повнозв'язну нейронну мережу (MLP) для розпізнавання рукописних цифр на основі класичного датасету MNIST.

#### 🎯 Мета
Вивчити архітектуру багатошарових нейронних мереж, опанувати принципи роботи алгоритму зворотного поширення помилки (Backpropagation) та навчитися оптимізувати гіперпараметри моделі за допомогою високорівневих API Keras/TensorFlow.

#### 🧩 Технічні деталі та компоненти
*   **Архітектура**: Глибока нейронна мережа (Deep Neural Network), що складається з вхідного шару `Flatten` (для перетворення матриці 28x28 у вектор), декількох прихованих шарів `Dense` та вихідного шару з функцією Softmax.
*   **Функції активації**: Використання **ReLU** (Rectified Linear Unit) для прихованих шарів, що забезпечує швидшу збіжність навчання та запобігає згасанню градієнта.
*   **Навчання та оптимізація**: Використання оптимізатора **Adam** для адаптивного підбору швидкості навчання та функції втрат `sparse_categorical_crossentropy`.
*   **Регуляризація**: Впровадження шарів **Dropout** для запобігання перенавчанню моделі на тренувальних даних.
*   **Аналіз результатів**: 
    *   Візуалізація матриці помилок (**Confusion Matrix**) за допомогою `Seaborn` для виявлення цифр, які мережа плутає найчастіше.
    *   Побудова графіків Accuracy та Loss для моніторингу процесу навчання.
*   **Інструменти**: Python, TensorFlow 2.16+, NumPy, Scikit-learn, Seaborn.

### 4️⃣ Лабораторна робота №4: Згорткові нейронні мережі (CNN) та Transfer Learning для класифікації зображень
Розробити систему класифікації складних візуальних образів з використанням сучасних архітектур та методів навчання на основі передачі знань.

#### 🎯 Мета
Опанувати принципи роботи згорткових шарів, вивчити методи регуляризації для великих обсягів візуальних даних та навчитися адаптувати передтреновані моделі (Fine-tuning) для вирішення конкретних прикладних задач.

#### 🧩 Технічні деталі та компоненти
*   **Архітектура CNN**: Використання шарів `Conv2D` для виділення ознак, `MaxPooling2D` для зменшення розмірності та `BatchNormalization` для стабілізації навчання.
*   **Перенос навчання (Transfer Learning)**: Використання потужних передтренованих архітектур, таких як **InceptionV3** або **Xception**, з відключеними верхніми шарами.
*   **Аугментація даних**: Застосування `ImageDataGenerator` для штучного збільшення тренувальної вибірки (повороти, зсуви, віддзеркалення), що дозволяє підвищити стійкість моделі до перенавчання.
*   **Обробка зображень**: Використання бібліотеки `Pillow` для нормалізації вхідних зображень та приведення їх до стандартного формату ($224 \times 224$ або $299 \times 299$).
*   **Оптимізація**: Налаштування швидкості навчання (Learning Rate) та використання Early Stopping для зупинки навчання при досягненні плато.
*   **Інструменти**: Python, TensorFlow (Keras), Pillow, Matplotlib.

### 5️⃣ Лабораторна робота №5: Реалізація архітектур сімейства Inception для розпізнавання складних об'єктів
Побудувати та дослідити повноцінну кастомну архітектуру Inception-v3, а також створити її оптимізовану версію (Mini-Inception) для класифікації зображень на прикладі датасету "Cats vs Dogs".

#### 🎯 Мета
Поглибити знання про складні архітектури нейронних мереж, опанувати модульний підхід до проектування шарів (Inception blocks) та навчитися працювати з автоматизованим завантаженням даних через Kaggle API.

#### 🧩 Технічні деталі та компоненти
*   **Автоматизація даних**: Інтеграція з Kaggle для завантаження датасету `tongpython/cat-and-dog` та створення збалансованих вибірок (Sampling).
*   **Архітектура Inception-v3 (Custom)**:
    *   **Stem-блок**: Початкові шари згортки зі специфічними кроками (strides) для швидкого зменшення розмірності.
    *   **Inception Modules (A, B, C)**: Реалізація паралельних гілок з фільтрами різних розмірів ($1 \times 1$, $3 \times 3$, $5 \times 5$) та факторизованих згорток ($1 \times 7$ та $7 \times 1$).
    *   **Global Average Pooling**: Використання замість повнозв'язних шарів для зменшення кількості параметрів та ризику перенавчання.
*   **Оптимізована модель (Mini-Inception)**:
    *   Створення полегшеної версії архітектури для швидких обчислень.
    *   Порівняльний аналіз кількості параметрів та обчислювальної складності (VRAM/Time).
*   **Методологія навчання**:
    *   **Data Augmentation**: Розширений конвеєр (повороти, зсуви, дзеркальне відображення).
    *   **Checkpointing**: Механізм збереження та завантаження моделі (`.h5`) для запобігання повторному навчанню.
*   **Оцінка та візуалізація**:
    *   Побудова детальної матриці помилок через `Seaborn`.
    *   Функція інференсу для прогнозування класу на довільних зовнішніх зображеннях з відображенням рівня впевненості (Confidence).
*   **Інструменти**: Python, TensorFlow/Keras, Kaggle API, Scikit-learn, Seaborn, Matplotlib.

### 6️⃣ Лабораторна робота №6: Реалізація архітектури Xception для розпізнавання об'єктів на відео
Розробити систему бінарної класифікації для розпізнавання логотипу бренду на відео на основі пошарової реалізації архітектури Xception.

#### 🎯 Мета
Опанувати принципи роботи сепарабельних згорток (Separable Convolutions), навчитися створювати складні архітектури з залишковими зв'язками (Residual connections) без використання готових моделей та реалізувати повний конвеєр обробки відеоданих з пост-обробкою сигналу.

#### 🧩 Технічні деталі та компоненти
*   **Генерація синтетичного датасету**:
    *   Автоматичне завантаження логотипів та випадкових фонів (API Picsum).
    *   Аугментація логотипів: випадковий поворот, масштабування та динамічна зміна прозорості (Alpha blending).
    *   Формування збалансованих вибірок `positive` (логотип на фоні) та `negative` (лише фон).
*   **Архітектура Xception (Custom Implementation)**:
    *   **Entry Flow**: Початкові згорткові шари з пакетною нормалізацією.
    *   **Middle Flow**: Використання `SeparableConv2D` для зменшення обчислювальної складності при збереженні точності.
    *   **Residual Connections**: Реалізація `layers.add()` для пропуску градієнта та стабілізації глибокої мережі.
    *   **Global Average Pooling**: Перехід від карт ознак до фінального класифікатора без перенавчання.
*   **Аналіз відеопотоку**:
    *   **Батчева обробка**: Порівняльний аналіз швидкості інференсу (FPS) при покадровій обробці проти групової (Batch processing).
    *   **Часова локалізація**: Визначення точних інтервалів появи об'єкта у форматі (кадри → секунди).
*   **Оптимізація та пост-обробка**:
    *   **Медіанна фільтрація**: Видалення "шуму" передбачень для уникнення мерехтіння результатів.
    *   **Gap Filling**: Алгоритм заповнення короткочасних прогалин у детекції для отримання цілісних часових сегментів.
*   **Інструменти**: Python, TensorFlow, OpenCV, SciPy (median_filter), Pillow, Tqdm.
